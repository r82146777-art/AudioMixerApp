# AudioMixerApp - اپلیکیشن میکس صوتی اندروید

این اپلیکیشن به شما اجازه می‌دهد دو فایل صوتی (اصلی و پس‌زمینه) را از حافظه گوشی انتخاب کنید، ولوم هر کدام را با اسلایدر تنظیم کنید، میکس کنید و به صورت **MP3** یا **WAV** ذخیره کنید.

## ویژگی‌ها
- انتخاب فایل اصلی و فایل پس‌زمینه از موزیک‌ها و فایل‌های گوشی
- اسلایدر تنظیم صدای هر فایل (۰ تا ۱۰۰٪)
- انتخاب فرمت خروجی: MP3 یا WAV
- دکمه **میکس و ساخت فایل**
- دکمه **پخش نتیجه** (پخش / مکث)
- دکمه **ذخیره در پوشه دانلودها**
- پشتیبانی کامل از **TalkBack** با برچسب‌های دسترسی‌پذیری فارسی برای نابینایان

## نحوه ساخت APK (دانلود و نصب)

### روش ساده (پیشنهادی):
1. پروژه را از GitHub دانلود کنید (Code → Download ZIP) یا Clone کنید.
2. فایل ZIP را از حالت فشرده خارج کنید.
3. Android Studio را باز کنید (اگر ندارید از [اینجا](https://developer.android.com/studio) دانلود کنید).
4. Open an Existing Project و پوشه پروژه را انتخاب کنید.
5. صبر کنید تا Gradle sync شود (اینترنت لازم است برای دانلود کتابخانه).
6. از منوی بالا: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
7. بعد از اتمام، روی **locate** کلیک کنید. فایل `app-debug.apk` آماده است.
8. APK را به گوشی منتقل کنید و نصب کنید (منبع ناشناس را فعال کنید).

### نیازمندی‌ها
- Android Studio Hedgehog یا جدیدتر
- JDK 17
- حداقل Android 7.0 (API 24)

## نحوه استفاده در اپ
1. اجازه دسترسی به فایل‌های صوتی را بدهید.
2. فایل اصلی را انتخاب کنید.
3. فایل پس‌زمینه را انتخاب کنید.
4. ولوم‌ها را تنظیم کنید.
5. فرمت (MP3 یا WAV) را انتخاب کنید.
6. روی «میکس و ساخت فایل» بزنید.
7. نتیجه را پخش کنید یا در Downloads ذخیره کنید.
