# AudioMixerApp - اپلیکیشن میکس صوتی اندروید

این اپلیکیشن به شما اجازه می‌دهد دو فایل صوتی (اصلی و پس‌زمینه) را انتخاب کنید، ولوم هر کدام را تنظیم کنید، میکس کنید و به صورت MP3 یا WAV ذخیره کنید.

## ویژگی‌ها
- انتخاب فایل اصلی و فایل پس‌زمینه از حافظه گوشی
- اسلایدر تنظیم صدا برای هر فایل
- انتخاب فرمت خروجی: MP3 یا WAV
- دکمه میکس و ساخت فایل
- پخش/مکث نتیجه
- ذخیره در پوشه Downloads
- پشتیبانی کامل از TalkBack با برچسب‌های دسترسی‌پذیری

## نحوه ساخت APK
1. پروژه را در Android Studio باز کنید
2. Build > Build Bundle(s) / APK(s) > Build APK(s)
3. فایل APK در app/build/outputs/apk/debug/ قرار می‌گیرد

## نیازمندی‌ها
- Android 7.0+ (API 24+)
- مجوز دسترسی به فایل‌های رسانه‌ای
